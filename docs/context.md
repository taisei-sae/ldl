# ldl 学習プロジェクト コンテキスト
 
このファイルは変わらない前提と計画だけをまとめたもの。現在の進捗はリポジトリ側を正とする。
 
## 1. 目的と題材
 
- 目的：深層学習の仕組みを理解し、論文に出てくるNNアーキテクチャ図の意味を読み取れるようになること。
- 題材：ドラレコやスマホで撮影した走行動画を使った、物体検出と車線認識。
- 実装はPyTorchで、すべて学習者自身が書く。
## 2. 学習者と環境
 
- 仕事でPythonとC++を使用。LiDARのSDK開発経験あり。計算機科学の基礎と大学教養レベルの数学は習得済み。
- 好み：理論を先に固めるより、先に手を動かして(学習・推論を実行して)から理論を追う。
- GPU：RTX 3060 Ti(VRAM 8GB)。入力解像度の縮小と混合精度(torch.autocast)を前提に計画している。
- OS：Windows上のWSL2で開発。
  - NVIDIAドライバはWindows側にのみインストールし、WSL2内のLinuxには入れない。
  - データや動画はWSL2側のファイルシステムに置く(/mnt/c 経由は読み込みが遅い)。
- PyTorch：公式インストールセレクタのpipコマンドでCUDA版を導入。pipのwheelはCUDAランタイム同梱のため、CUDA Toolkitは不要。Pythonは3.10以上。
- 周辺ライブラリ：opencv-python(動画入出力)、torchinfo(層ごとの形状確認)、tensorboard(学習曲線)。

## 4. 進め方
 
- 各ステップは「動かす → 壊す → 理由を調べる」の順で進める。
- 理論の教材は通読せず、実験で生じた疑問を引く辞書として使う。
- 論文の図を読むときは、矢印ごとにテンソル形状(C×H×W)を書き込み、損失関数を自分の言葉で説明できるまで読み、最後にアブレーション表を確認する。
## 5. 学習計画
 
### ステップ1：学習済み検出器で推論(約1週)
- やること：torchvisionのCOCO学習済み検出器で、自分の動画(昼・夜・雨・トンネルなど)をフレームごとに推論し、箱とラベルを描いた動画を書き出す。前処理は各重みに付属する weights.transforms() を使う。
- 比較するモデル(COCO val2017のBox mAP)
  - Faster R-CNN ResNet50-FPN v2：46.7(2段階型)
  - RetinaNet ResNet50-FPN v2：41.5(1段階型、アンカーあり)
  - FCOS ResNet50-FPN：39.2(1段階型、アンカーなし)
- 観察：スコア閾値(0.3／0.5／0.8)による誤検出と見逃しの入れ替わり、小さい物体・夜間・逆光・雨での崩れ方、フレーム間のちらつき、入力解像度と速度の関係、データセットの定義による限界(信号の色が分からない等)。
- 完了の目安：失敗シーンを集め、疑問リストが5個程度たまる。
- 文献：COCO(arXiv:1405.0312)、Faster R-CNN(arXiv:1506.01497)のアンカーとRPNの部分、FCOS(arXiv:1904.01355)の概要。補助としてd2l.aiのコンピュータビジョンの章(バウンディングボックス、アンカー、物体検出)。
### ステップ2：既存モデルのファインチューン(2〜3週)
- やること：BDD100Kの一部で検出器を再学習し、損失曲線と検証精度を観察する。学習率を極端に変える、データを減らして過学習させる等で壊す。
- 後追い理論：損失関数、SGDとAdam、転移学習、過学習と正則化(d2l.aiの該当章)。
- 文献：BDD100K(arXiv:1805.04687)。
### ステップ3：小さなCNNを自作して壊す(2〜3週)
- やること：分類用の小さなCNNを組み、層を深くする、BatchNormを外す、残差接続を付け外しするなどして学習の崩れ方を見る。
- 到達目標：ResNet論文の構成表から全層の出力形状を書き出せる。
- 文献：VGG(arXiv:1409.1556)、Batch Normalization(arXiv:1502.03167)、ResNet(arXiv:1512.03385)。
### ステップ4：車線セグメンテーション(3週)
- やること：U-Netで車線を学習させる。細い車線が消えて背景ばかり予測される現象(クラス不均衡)に向き合う。
- 視点：車線を「画素分類」と見るか「行ごとの位置推定」と見るかで設計が変わる。
- 文献：FCN(arXiv:1411.4038)、U-Net(arXiv:1505.04597)、SCNN(arXiv:1712.06080、CULaneデータセット)、Ultra-Fast-Lane-Detection(arXiv:2004.11757)。
### ステップ5：検出器を自作(5〜6週、最難関)
- やること：FCOSを再現する。学習が進まない原因を探る過程を学びの中心にする。
- 重点：ラベル割り当て(どの予測にどの正解を担当させるか)。
- 文献：FCOS(arXiv:1904.01355)、FPN(arXiv:1612.03144)、RetinaNet／Focal loss(arXiv:1708.02002)、CenterNet(arXiv:1904.07850)、遡ってFaster R-CNN(arXiv:1506.01497)。
### ステップ6：統合と発展
- やること：YOLOPの図を読み、検出と車線を1つのモデルに統合する(共有バックボーン＋ネック＋タスク別ヘッド)。
- 論点：損失の重み付け、タスク間の干渉。
- 文献：YOLOP(arXiv:2108.11250)、HybridNets(arXiv:2203.09035)。
- 発展：ViT(arXiv:2010.11929)、DETR(arXiv:2005.12872)、Lift-Splat-Shoot(arXiv:2008.05711)、BEVFormer(arXiv:2203.17270)。鳥瞰図(BEV)系はLiDARの知識が活きる分野。
